# 🖥️ Friday Desk Review (1 Hour)

**Purpose:** Weekly reset - digital only, no physical tasks
**When:** Friday afternoon
**Duration:** 60 minutes

---

## ⏱️ Time Blocks

| Block | Time | Focus |
|-------|------|-------|
| Clear | 15 min | Digital inboxes, brain dump |
| Current | 15 min | Calendar, projects, tasks |
| Life Pulse | 10 min | Quick life areas scan |
| Career | 10 min | Learning, network, wins |
| Plan | 10 min | Next week priorities |

---

## 1️⃣ Clear (15 min)

### Digital Inbox Zero

- [ ] Email - process to zero or schedule
- [ ] Slack/messages - clear notifications
- [ ] Browser tabs - close or capture to notes
- [ ] Notes app - process loose captures
- [ ] Downloads folder - quick sort/delete

### Brain Dump

- [ ] Open loops still in head → task manager
- [ ] "What am I forgetting?" sweep

---

## 2️⃣ Current (15 min)

### Past Week Calendar

- [ ] Review meetings - any follow-ups needed?
- [ ] Capture learnings/decisions from meetings

### Upcoming Week Calendar

- [ ] Check for conflicts
- [ ] Identify prep needed for meetings
- [ ] Block focus time for deep work

### Projects & Tasks

- [ ] Each active project has clear next action?
- [ ] Archive/close completed items
- [ ] Identify stalled items - what's blocking?
- [ ] Update task priorities

---

## 3️⃣ Life Pulse (10 min)

Quick 1-10 rating + one sentence why:

| Area | Score | Note |
|------|-------|------|
| 🏃 Health/Energy | /10 | |
| 💰 Finances | /10 | |
| 👥 Relationships | /10 | |
| 🧘 Mental State | /10 | |
| 🎯 Progress Feeling | /10 | |

- [ ] If any area <6, identify one small action

---

## 4️⃣ Career (10 min)

- [ ] **Wins log** - what did I accomplish this week?
- [ ] **Learning** - queue one article/video/course for next week
- [ ] **Network** - who to reach out to? Schedule it
- [ ] **Visibility** - anything worth sharing/documenting?
- [ ] **Skills gap** - what blocked me that I should learn?

---

## 5️⃣ Plan (10 min)

- [ ] Define **Top 3 priorities** for next week
- [ ] Add one **"want to do"** (not just obligations)
- [ ] Reality check - realistic given calendar?
- [ ] Identify **potential blockers** - what might derail?
- [ ] Set intention for the week

---
