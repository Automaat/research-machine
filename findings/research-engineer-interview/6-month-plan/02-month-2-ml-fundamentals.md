# 📅 Month 2: ML Fundamentals (80-100 hours)

**Tags:** #career #ML #preparation #month-2 #ml-fundamentals

---

## 🎯 Goals

- Master core ML concepts (supervised/unsupervised, loss functions, optimization)
- Implement classical algorithms from scratch
- Build intuition for bias-variance tradeoff

---

## 📆 Week 1-2: Core ML Concepts

### Learning Paradigms

- Supervised learning (classification, regression)
- Unsupervised learning (clustering, dimensionality reduction)
- When to use which

### Regression

- Linear regression (closed-form + gradient descent)
- Logistic regression (sigmoid, cross-entropy loss)
- Regularization (L1/L2)

### Optimization

- Gradient descent variants
- Learning rate intuition
- Convergence criteria

### Model Evaluation

- Bias-variance tradeoff
- Overfitting vs underfitting
- Train/val/test splits
- Cross-validation

---

## 📆 Week 3-4: Classical Algorithms

### Tree-Based Methods

- Decision trees (entropy, information gain, Gini)
- Random forests (bagging, feature importance)
- Boosting basics (AdaBoost, gradient boosting)

### Distance-Based Methods

- k-Nearest Neighbors (distance metrics, k selection)
- Support Vector Machines (margins, kernel trick intuition)

### Dimensionality Reduction

- PCA (variance maximization, eigenvector interpretation)
- t-SNE basics (for visualization)

### Clustering

- k-means (Lloyd's algorithm, elbow method)
- Hierarchical clustering basics

## ✅ Milestone

**Implement 5 algorithms from scratch (no sklearn):**

1. ☐ Linear Regression (with gradient descent)
2. ☐ Logistic Regression
3. ☐ Decision Tree
4. ☐ k-Nearest Neighbors
5. ☐ k-Means Clustering

**Why from scratch:** Forces deep understanding of the math. You'll debug neural networks later - this builds that muscle.
