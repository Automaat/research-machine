# 📅 Month 5: Specialization + Projects (80-100 hours)

**Tags:** #career #ML #preparation #month-5 #specialization #projects

---

## 🎯 Goals

- Choose and deep-dive into 1 ML domain
- Read domain-specific papers
- Build portfolio project demonstrating expertise
- Create evidence for interviews

---

## 📆 Week 1-2: Choose Domain & Deep Dive

### Domain Selection

Pick ONE domain based on:
- Your interest and curiosity
- Target company/role focus
- Existing background leverage

| Domain | Key Topics | Good If You... |
|--------|------------|----------------|
| **NLP** | BERT, GPT, T5, instruction tuning, RAG | Like language, text, chatbots |
| **Computer Vision** | ViT, CLIP, Stable Diffusion, segmentation | Visual thinker, image data |
| **Reinforcement Learning** | PPO, SAC, world models, RLHF | Like game theory, control |
| **Generative AI** | VAEs, GANs, Diffusion, Flow matching | Creative, generative focus |

### Deep Dive Activities
- Read 10-15 key papers in domain
- Implement 2-3 algorithms from papers
- Understand state-of-the-art benchmarks
- Know open problems

---

## 📆 Week 3-4: Build Portfolio Project

### Project Requirements

Build evidence that you can do ML research:

- **End-to-end**: Data → Model → Evaluation → Analysis
- **Non-trivial**: Not just tutorial code
- **Documented**: README, approach, decisions, results
- **Public**: GitHub with clean code

### Project Ideas by Domain

**NLP:**
- Fine-tune LLM for specific task
- Build RAG system with evaluation
- Implement paper from scratch

**Computer Vision:**
- Object detection on custom dataset
- Image generation with Stable Diffusion fine-tuning
- Video understanding task

**RL:**
- Train agent on complex environment
- Implement PPO/SAC from scratch
- Multi-agent scenario

**Generative AI:**
- Train diffusion model on custom data
- Implement flow matching
- Controllable generation

## ✅ Milestone

**Complete 1 substantial project, publish on GitHub**

### Project Checklist
- [ ] Clear problem statement
- [ ] Data pipeline implemented
- [ ] Model trained and evaluated
- [ ] Results analyzed and documented
- [ ] Code is clean and readable
- [ ] README explains everything
- [ ] Hosted on GitHub

### README Template
```markdown
# Project Title

## Overview
What problem does this solve?

## Approach
How did you solve it?

## Results
What did you achieve? (metrics, visualizations)

## Usage
How to run the code?

## Learnings
What did you learn? What would you do differently?
```

## 💡 Tips for Paper Reading

1. **First pass (10 min):** Title, abstract, figures, conclusion
2. **Second pass (1 hr):** Intro, method overview, experiments
3. **Third pass (2+ hrs):** Full details, reproduce if needed

**Goal:** 10-15 papers this month, 3-5 deep reads
