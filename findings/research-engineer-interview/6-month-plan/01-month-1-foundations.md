# 📅 Month 1: Foundations (80-100 hours)

**Tags:** #career #ML #preparation #month-1 #foundations

---

## 🎯 Goals

- Refresh math fundamentals (linear algebra, calculus, probability)
- Build proficiency with Python ML stack (NumPy, Pandas, PyTorch)
- Develop tensor manipulation intuition

---

## 📆 Week 1-2: Math Refresh

### Linear Algebra
- Vectors, matrices, matrix multiplication
- Eigenvalues, eigenvectors
- Matrix decompositions (SVD basics)

### Calculus
- Gradients, partial derivatives
- Chain rule (critical for backprop)
- Multivariate calculus basics

### Probability & Statistics
- Probability distributions
- Bayes theorem
- Expected value, variance

---

## 📆 Week 3-4: Python ML Stack

### NumPy
- Array operations & broadcasting
- Vectorization (avoid loops!)
- Advanced indexing

### Pandas
- DataFrames, Series
- Data manipulation & cleaning
- Groupby, merge, pivot

### Visualization
- Matplotlib basics
- Seaborn for statistical plots

### PyTorch Basics
- Tensor operations
- einsum mastery
- Automatic differentiation basics
