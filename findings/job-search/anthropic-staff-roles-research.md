**Your profile:** Go, Kubernetes, distributed systems, service mesh, observability, CNCF maintainer

### Best Matches (ranked)

1. **AIRE (AI Reliability)** - Observability + reliability + open-source contributions valued. $325K-$485K base.
2. **Staff+ Infrastructure** - K8s clusters at massive scale, Go, cloud infra. Core infra team.
3. **Autonomous Agent Infrastructure** - Go, cloud-native, containers, greenfield. $320K-$485K.
4. **Staff Platform (Service Infra team)** - Service mesh + observability explicitly mentioned. $320K-$405K.
5. **Cloud Inference** - Multi-cloud K8s, observability, scale. $300K-$485K.
6. **Senior Systems (London)** - If London is viable. GBP 240K-325K.

### Key Differentiators for Your Profile

- CNCF maintainer status is rare and explicitly valued (AIRE role mentions open-source contributions)
- Service mesh experience directly maps to Service Infra team and AIRE
- Go proficiency listed as desired language across most infra roles
- Kubernetes expertise is core requirement for nearly every role
- Observability experience maps to AIRE, Service Infra, and Cloud Inference

### Gaps to Address

- ML infrastructure (GPUs, TPUs) - not required but preferred for some roles
- Python proficiency - primary language at Anthropic (more than Go)
- AI/ML domain knowledge - helpful but not blocking
