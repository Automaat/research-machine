# Base Questions

Core questions for all skill types.

---

## Q1: Purpose & Trigger

**Question:** When would you invoke this skill? What triggers its use?

**Options:**
- Daily/scheduled task
- On-demand when I need [specific thing]
- As part of another workflow
- Other

**Use answer for:** Determining automation vs on-demand, state management needs

---

## Q2: Inputs

**Question:** What information do you provide when invoking the skill?

**Options:**
- URL or link
- Search query or topic
- File path
- Structured data (JSON, etc.)
- No input (uses defaults/state)
- Other

**Use answer for:** Argument parsing, validation requirements

---

## Q3: Outputs

**Question:** What should the skill produce?

**Options:**
- Markdown document (saved to file)
- Structured data (JSON)
- Summary in chat (no file)
- Multiple files
- Other

**Use answer for:** Output template, save locations

---

## Q4: Quality Criteria

**Question:** How do you know the output is good? What makes it fail?

**Options:**
- Completeness (covers all X)
- Accuracy (verified information)
- Format (specific structure required)
- Actionability (clear next steps)
- Other

**Use answer for:** Quality checklist, verification phase
